# Company logos

Place real company logo files here and update the `logo` field in `src/content/site.ts`.

Suggested filenames:

- `nevobit.svg`
- `prooving.svg`
- `helebba.svg`
- `loobic.svg`
- `lytos.svg`
- `itaaj-realty.svg`

The home group band renders the image when `logo` is different from `/img/logo192.png`; otherwise it falls back to a text wordmark.
